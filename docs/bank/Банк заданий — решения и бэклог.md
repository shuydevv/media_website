## Тренажёр «Верные суждения» ✅ v1 (06.11.2026)

Сделан, механика — `docs/statements/Верные суждения — механика.md` (она
главнее этого раздела). Ниже — исходный черновик обсуждения.

Отдельный тренажёр (как термины и даты), не экран банка. Работает на телефоне и
на компьютере.

**Материал.** Задания «Выберите верные суждения» (линии 2, 5, 8, 10, 14 по
нумерации ege-hub): 818 заданий → 4097 суждений, после склейки одинаковых —
~3100. Верно/неверно — из ключа ответа задания. Пояснение — из разбора задания
по пунктам; только у ~1/3 суждений в разборе есть причина, у остальных — голое
«да, верно». Ключ и разбор расходятся примерно в 440 местах (грубая оценка) —
проверять при импорте.

**Пояснения ✅ (вариант «В», 06.11.2026).** Запуск — только на суждениях с
нормальным пояснением (~1000–1400). Остальные (~2700, голое «да/нет, верно»)
добавляются позже: ИИ пишет черновик пояснения и «как было бы верно», автор
вычитывает пачками, после вычитки суждение попадает в тренажёр. Импорт
должен хранить такие суждения (не выбрасывать), просто не выдавать ученику.

**Доступ ✅.** В открытый доступ ничего не выкладываем — только ЛК.

**Решения от 06.11.2026 ✅**
- Название — **«Верные суждения»**. Станция в «Зале обществоведов»
  (`config/trainers.php`, `halls.social`), доступ — как у остальных тренажёров.
- Корм — за законченную сессию, с дневным лимитом (как в терминах).
- Сессия — 15 суждений, в конце «Ещё 15».
- Персонажи (Пыша, Кеша, Душнила) — да, выпадают случайно.
- «Собери задание» — потом 💡.
- Темы ege-hub с нашими `Section`/`Topic` для этого тренажёра не сопоставляем:
  блоки берутся из раздела задания, подпись «Суждение о …» — из текста задания.
  Сопоставление понадобится позже — для фильтров банка и карты навыков.
- Нумерация линий ege-hub — автор подтвердил, сверять не нужно.
- Тексты (акула, персонажи, рыба на дашборде, станция) — пишет Claude по
  образцу `config/fish_speech.php` и `config/terms.php`, автор одобряет.

**Выбор.** Ученик выбирает блоки (Человек и общество, Экономика, Социальные
отношения, Политика, Право) или «Все блоки».

**Экран.** Сверху — о чём суждение («Суждение о социальной стратификации» —
из формулировки задания: без этого часть суждений теряет смысл). Карточка с
суждением. Ответ: «Верно» / «Неверно» / «Не знаю».
Телефон — свайп вправо/влево или кнопки; компьютер — кнопки и клавиши
← / → (неверно / верно), ↓ — «не знаю», Enter — дальше.

**После ответа** — всегда, и после верного тоже: вердикт + пояснение.
Для неверного суждения — как было бы верно. Дальше — только кнопкой.

**Из диагностики берём** (`docs/diagnostic/ТЗ…`, механика `swipe`):
кнопка «Не знаю» (= ошибка для повторения, показывает ответ), пояснение после
каждого ответа, серии «🔥 N подряд», акула-ведущая, свой неверный выбор —
мягким цветом, итог с сильными сторонами и точками роста по блокам.
По желанию, если дёшево: оформление `chat` — суждение говорит Пыша, Кеша
или Душнила.

**Итог сессии.** N из M, по блокам, список ошибок с пояснениями, кнопка
«Повторить ошибки».

**Последний шаг сессии (идея):** «Собери задание» — исходное задание ЕГЭ
целиком (все 5 суждений), мостик к формату экзамена.

## Станция «Задания» ✅ решения 07.11.2026

- Делаем станцию «Задания» 🥊 в «Зале обществоведов» (не каталог в меню).
- Вторая часть — сразу, вместе с первой.
- Проверка второй части — самопроверка: ответ ученика → образец
  (`decision` из выгрузки) + чек-лист по критериям номера → ученик сам
  ставит баллы. Кнопка «Проверить ИИ» (ClaudeGrader) с дневным лимитом — потом 💡.
- Задания 19/20 со ссылкой на текст (129 шт.): 8 содержат текст сами,
  11 привязаны к тексту задания 17/18 (`text_links`), остальные 107
  переписаны так, чтобы текст был не нужен (`rewrites`), 3 — дубли.
  Всё — в `docs/bank/rewrites.json`, импорт применяет поверх выгрузки,
  исходник не правится. ❓ Ждёт вычитки автора. В 4 заданиях (16852,
  21790, 22382, 47598) образец ответа заменён — поле `decision`, причина
  в `note`.

## Аналитика ✅ (понравилось, делать)

- Настоящая сложность — по фактическому проценту решений, а не из источника.
- Самые частые неверные ответы («73% выбрали 3») — материал для уроков и
  подсказка ученику «ты попал в частую ловушку».

- Карта навыков «линия × тема».

Для этого с первого дня логировать каждый ответ: что ответил, верно ли,
«не знаю», время на ответ — как `diagnostic_answers`.
