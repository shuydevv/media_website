# Механика тренажёра терминов (задание 18)

Версия 4 от 13 октября 2026. Исходная версия от 10 октября лежит в `_original/`.
База терминов — `egkh_terms_18.json` в этой же папке.

## Коротко

Ученик каждый день делает до двух вещей: повторяет термины, у которых подошёл срок, и изучает пять новых. За каждую из двух сессий он получает до 3 корма. Сверх этого есть свободная тренировка, которая ни на что не влияет.

| Параметр | Значение |
|---|---|
| Терминов в базе | 189: 65 базовых, 81 продвинутый, 43 экспертных |
| Новых терминов в день | 5, одна порция |
| Повторение в день | одно, до 20 терминов |
| Сетка интервалов | 1 → 3 → 7 → 14 → 30 дней, дальше каждые 30 |
| Корм за сессию | 3 / 2 / 1 / 0, максимум 6 в день |

## База терминов

### Поля термина

| Поле | Что это |
|---|---|
| `slug` | постоянный ключ термина; по нему идёт перезаливка |
| `title` | основное название — его ученик вводит в квадратики |
| `qualifier` | уточнение («как система», «в праве»); не вводится |
| `other_names` | другие названия; засчитываются как верный ответ |
| `image` | имя файла фотографии |
| `code` | код темы по кодификатору (`2.10`); первая цифра — раздел |
| `priority` | уровень: 1 — базовый, 2 — продвинутый, 3 — эксперт |
| `parent` | родовое понятие (у «Закона» это НПА) |
| `confusable_with` | термины, с которыми этот путают |
| `pair_notes` | заметки преподавателя к парам понятий (необязательно) |
| `features` | признаки по порядку: `id`, `text`, `group` |

### Название, уточнение, другие названия

Всё, что в исходных названиях стояло в скобках, через слэш или после «как», вынесено из `title`:

- синоним уходит в `other_names`: «Научное познание (наука)» → «Научное познание» + «Наука»;
- уточнение уходит в `qualifier`: «Общество (как система)» → «Общество» + «как система».

После этого у нескольких терминов одинаковый `title`: два «Общества», две «Экономики», две «Семьи», два «Труда», две «Политические власти». Для ввода это не проблема — ответ одинаковый. Различает их уточнение.

Где уточнение видно:

- в квизе по признакам, на карточке знакомства и на карте терминов — всегда;
- в способе с квадратиками — только после ответа.

### Формулировки признаков

Тексты признаков не переписываются: задание 18 требует именно таких формулировок, и тренажёр должен приучать к ним. Это касается и признаков, в которых читается название термина («гражданство является правовым состоянием»). В способе с квадратиками это даёт ученику небольшую подсказку — так и задумано.

Самостоятельно можно править только опечатки и знаки в конце. Название термина из признака тоже не убирается.

Упрощать тяжёлые формулировки можно, но только с согласования автора и без потери смысла. 17 октября 2026 так упрощены 56 признаков — длинные и склеенные через слэш. Упрощённая формулировка заменяет исходную, второй версии нет, поэтому она же идёт в квиз и «лишний признак». Правила, выработанные на них:

- нейтральный учебный язык, без разговорного;
- термины-якоря остаются: «ценовое лидерство», «деликтоспособность», «ГК РФ», «опосредованный характер»;
- в экономике и праве не терять элементы смысла: в ВВП входят товары **и услуги**; политическое участие — это и решения, и выбор представителей;
- пустые хвосты-перечни убираются («при участии иных организаций, должностных лиц и граждан»);
- если упрощение не добавляет ясности, формулировка остаётся как есть.

Копия файла до упрощения — `_original/egkh_terms_18.before-simplify-2026-10-17.json`.

### Группы признаков

Два признака с одинаковым `group` никогда не попадают в один вопрос квиза: ни как ответ и дистрактор, ни как два дистрактора. Группа — это либо дубль («общая культура и язык» у этноса и нации), либо признаки, которые верны сразу для нескольких терминов («в письменной форме» у брачного договора, трудового договора и НПА).

Сейчас в базе 61 группа, в них 151 признак. Список живой: он пополняется по репортам учеников.

### Родовое понятие (`parent`)

Признаки родового понятия верны и для видового: «содержит нормы права» (НПА) верно для закона. Поэтому термины, связанные по линии `parent` в любую сторону и через любое число шагов, не дают дистракторы друг другу. Соседи по родителю (обыкновенная и привилегированная акция) — дают, это хороший контраст.

Связь проставлена у 51 термина.

### Заметки к парам понятий (`pair_notes`)

Короткое пояснение, чем два понятия отличаются. Рыба говорит его дословно, когда ученик спутал эту пару: ввёл название одного вместо другого или выбрал в квизе признак второго.

```json
"pair_notes": {
  "valovoi-nacionalnyi-produkt-vnp": "ВВП считают по территории, ВНП — по производителю"
}
```

- Ключ — `slug` другого термина, значение — заметка одной фразой.
- Заметка действует в обе стороны; записать её достаточно у одного термина из пары.
- Поле необязательное. Заметки добавляются постепенно, через перезаливку файла.

Отличия между понятиями берутся только отсюда. Автоматически из списков признаков они не выводятся: список в базе — это признаки, которые засчитываются в ответе на задание 18, а не всё, что о понятии верно. У этноса общность территории не записана, хотя она у него есть; фраза «у этноса этого нет» была бы ошибкой.

## Порядок изучения

1. Три уровня по полю `priority`: базовый (1), продвинутый (2), эксперт (3). Изучаются по порядку: следующий уровень закрыт, пока в предыдущих есть хотя бы один неизученный термин. Родовое понятие никогда не стоит на уровне выше своего вида — иначе ученик выучил бы «Закон» раньше «НПА».
2. Порция — пять терминов из разных разделов кодификатора: по одному из каждого раздела, в котором ещё есть неизученные. Вперемешку термины запоминаются легче, а все разделы продвигаются одновременно.
3. Внутри раздела — по `code` (по порядку тем), при равенстве по `id`.
4. Когда раздел заканчивается, его место в порции занимают следующие по кругу. Последняя порция уровня может быть меньше пяти.

Идеальный ученик проходит базовый уровень за 13 дней, продвинутый — ещё за 17, экспертный — за 9; всю базу — за 39.

## День ученика

Сутки считаются по календарным дням в часовом поясе платформы. Сроки повторения хранятся датами, без времени: термин, изученный сегодня в любое время, ждёт повторения завтра.

### Повторение дня

- В него попадают термины, у которых срок наступил (сегодня или раньше).
- Не больше 20 терминов. Если ждёт больше — берутся самые просроченные, остальные переносятся на завтра.
- Одно повторение в день. Закончил — следующее завтра.

### Новые термины

Порция открывается, когда выполнены все три условия:

1. не осталось терминов с наступившим сроком;
2. сегодня порция ещё не изучалась;
3. в открытом уровне есть неизученные термины.

Так долги не копятся: пока ученик не разобрал завал, новое не добавляется, а сам завал разбирается не быстрее 20 терминов в день. Ученик, вернувшийся после двух недель с 60 просроченными терминами, закрывает их за три дня.

Потолок 20 подобран под сетку: у идеального ученика на пике ровно 20 повторений в день, в потолок он не упирается.

## Сетка интервалов

| Шаг | Следующее повторение через |
|---|---|
| 1 | 1 день |
| 2 | 3 дня |
| 3 | 7 дней |
| 4 | 14 дней |
| 5 | 30 дней, дальше каждые 30 |

Почему так:

- Интервалы растут примерно в 2–2,5 раза — как в SM-2, на котором построен Anki.
- Потолок 30 дней. По Cepeda et al. (2008), для срока удержания в несколько месяцев оптимальный разрыв между повторениями — порядка 2–4 недель. Растягивать дальше незачем.
- Каждый термин гарантированно повторяется в последний месяц перед экзаменом.

Термин доходит до последнего шага за 25 дней, вся база — примерно за два месяца от старта. После этого нагрузка — 6–7 терминов в день.

### Как меняется шаг

- **Успех** (вспомнил сам с первой попытки): шаг +1, но не выше 5. Следующий срок — сегодня плюс интервал нового шага.
- **Ошибка**: шаг −1, но не ниже 1. Следующий срок — сегодня плюс интервал нового шага.
- Учитывается только первая попытка в сессии. Если термин вернулся на круг и со второго раза отвечен верно, это по-прежнему ошибка.
- Опоздание не штрафуется: повторил на 10 дней позже срока и верно — шаг растёт как обычно.

## Изучение новых терминов

Каждый термин порции проходит три шага: карточка знакомства → угадать термин (способ А) → задание на признаки: квиз (способ Б) или «лишний признак» (способ В).

Шаги разных терминов идут вперемешку, а не блоками. Карточки не показываются все пять подряд: как только ученик отметил «Запомнил» на трёх, его спрашивают про первый термин, и только потом показывают четвёртую карточку.

Устроено это одним правилом: следующий шаг термина встаёт в очередь не сразу, а через два других шага.

- **Карточка.** Фото, название, уточнение, другие названия, все признаки. Две кнопки:
  - «Запомнил» — через два шага придёт задание А по этому термину;
  - «Ещё не запомнил» — через два шага карточка покажется снова.
- **Способ А.** Верный ответ — через два шага придёт задание на признаки по этому термину.
- **Способ Б или В.** Верный ответ — термин выучен.

Ошибка в любом задании возвращает его в конец очереди; термин повторяется, пока не будет отвечен верно.

После сессии все термины порции встают на шаг 1 независимо от ошибок. Ошибки влияют на корм и на список «Стоит перечитать».

## Повторение

- У каждого термина одно задание. Ходы чередуются от повторения к повторению: первое повторение после изучения — способ А, следующее — задание на признаки, и так далее.
- Задание на признаки — это квиз (Б) или «лишний признак» (В). Внутри сессии они идут по очереди; с какого начать, выбирается случайно.
- Ошибка возвращает термин в конец очереди; он повторяется тем же способом, пока не будет отвечен верно.
- Результат каждого термина записывается сразу, а не в конце сессии. Если ученик вышел посередине, отвеченное сохранено, а сессия продолжается с того же места до конца дня.

## Способ А: угадать термин

На экране: размытое фото, признаки, ряд квадратиков.

- Квадратиков столько, сколько букв в `title`. Пробелы и дефисы пропускаются, ряд сплошной. Самое длинное название — 39 букв, на телефоне ряд переносится.
- **Кнопки «Проверить» нет.** Ответ проверяется сам, как только заполнена последняя клетка. Короткое другое название («ВВП») клетки не заполняет — его отправляет Enter.
- **«Открыть букву»** открывает следующую букву слева. Доступны две подсказки; после второй кнопка меняется на «Показать ответ».
- **«Показать ответ»** — ошибка, термин уходит в конец очереди. Предупреждения перед этим нет.
- **Попытка одна.** Неверный ввод — ошибка.

Что считается верным:

- ответ совпал с `title` или с любым из `other_names`;
- регистр, ё/е, пробелы и дефисы не учитываются;
- одна опечатка прощается, если в названии шесть букв или больше («валовый» вместо «валовой»).

После ответа фото проявляется, название встаёт в клетки, под ними появляются уточнение и другие названия. Отдельной плашки с ответом нет.

Буквы подсказки и проверка ответа приходят с сервера: правильного названия в странице нет. Фото отдаётся под обезличенным именем — исходное имя файла совпадает с названием термина.

## Способ Б: квиз по признакам

На экране: фото, название с уточнением, список признаков пустыми слотами в порядке базы. Признаки разбираются по одному.

За один квиз спрашивается не больше четырёх признаков. Если у термина их пять или шесть, берутся случайные четыре, каждый раз заново: за несколько повторений ученик увидит все, а квиз не растягивается.

Для активного слота — четыре варианта столбиком: один верный и три дистрактора.

**Откуда берутся дистракторы.** Запрещены:

- признаки этого же термина;
- признаки терминов, связанных с ним по линии `parent`;
- признаки из той же группы, что верный вариант;
- два дистрактора из одной группы;
- варианты с одинаковым текстом.

Из оставшихся берутся по порядку: сначала из терминов `confusable_with`, потом из того же раздела кодификатора, потом из любых.

Чтобы верный вариант нельзя было вычислить без знаний:

- в одном квизе дистракторы не повторяются от вопроса к вопросу;
- из `confusable_with` в один вопрос идёт не больше двух дистракторов, третий — из раздела.

**Ответ.** Клик по варианту сразу засчитывается.

- Верно — слот заполняется, сразу активен следующий.
- Неверно — показывается верный вариант, по «Далее» ученик переходит к следующему термину. Оставшиеся признаки этого термина не спрашиваются: термин вернётся в конец очереди и будет пройден заново целиком.

Одна ошибка в любом признаке — ошибка по термину целиком: шаг считается по термину, а не по признаку.

## Способ В: лишний признак

На экране: фото, название с уточнением и четыре признака. Три из них — признаки этого термина, один — чужой. Нужно найти чужой. Если у термина всего два признака, вариантов три.

- Чужой признак подбирается теми же правилами, что и дистракторы квиза.
- Клик сразу засчитывается. После ответа лишний подсвечивается зелёным и подписывается, от какого он понятия.
- Ошибка — термин уходит в конец очереди.

Чередуется с квизом, чтобы задания на признаки не были однообразными: квиз проверяет, узнаёт ли ученик признак, «лишний признак» — отличает ли он его от чужого.

## Признаки, верные и для самого термина

Дистрактор в квизе и чужой признак в «лишнем» не должны быть правдой про сам термин. Поэтому из кандидатов убираются признаки, которые стоят в одной группе с **любым** признаком термина или совпадают с ним по тексту — не только с тем, о котором сейчас вопрос. Пример: «общая культура и язык» у нации — дубль признака этноса, и рядом с любым вопросом про этнос он был бы верным утверждением.

## Как показываются ошибки

Красного цвета в тренажёре нет: он демотивирует. Верный ответ — зелёный, неверно выбранный вариант в квизе и «лишнем признаке» — жёлтый, неверно введённое название — нейтральное серое. Сообщений вроде «термин вернётся в конец очереди» тоже нет — термин просто появляется снова.

## Свободная тренировка

Заменяет платную досрочную сессию из первой версии.

- Открыта, когда повторение дня пройдено или повторять сегодня нечего. Иначе ученик прогнал бы термины перед повторением и получил бы рост шагов без запоминания.
- В неё входят все изученные термины.
- Порядок — сначала с самым низким шагом, внутри шага случайно. Слабые места идут первыми, и ученик дойдёт до них, даже если выйдет через 15 минут.
- Выйти можно в любой момент. При следующем входе круг продолжается; после полного круга начинается новый.
- Способы А и Б чередуются, ошибка возвращает термин в конец очереди.
- Не даёт корм, не меняет шаги и сроки.

Слабость термина — это его текущий шаг, а не число ошибок за всё время. Термин с десятью старыми ошибками, дошедший до шага 5, слабым не считается.

## Корм

Корм начисляется за законченную сессию, один раз: за повторение дня и за изучение новых.

| Доля верных с первой попытки | Корм |
|---|---|
| 100% | 3 |
| от 80% | 2 |
| от 60% | 1 |
| меньше | 0 |

- В повторении считаются термины, в изучении — задания А и Б по каждому термину (обычно десять).
- Сессия, не законченная до конца дня, корма не приносит.
- Максимум 6 корма в день, около 40 в неделю — на уровне корма за домашки.
- Тратится корм как раньше: кормление рыбы, фоны, аксессуары. В самом тренажёре трат нет.

## Кнопка «Сообщить об ошибке»

Только в квизе по признакам. Один клик, комментарий по желанию. Сохраняются: ученик, термин, верный признак, три показанных дистрактора.

Репорты приходят в админку, сгруппированные по признаку. Несколько репортов на один признак от разных учеников — повод добавить группу. База правится вручную.

## Доступ

Тренажёр открыт, если выполнено хотя бы одно:

- у ученика активный доступ к курсу обществознания;
- у ученика активный доступ к курсу, который админ привязал к тренажёру дополнительно;
- админ выдал доступ этому ученику лично — курсы для этого не нужны.

## Экраны ученика

**Главная тренажёра.** Блок «Сегодня» из трёх строк: повторение, новые термины, свободная тренировка. У недоступной строки написана причина («сначала повтори», «новые завтра»). Если повторять сегодня нечего, в строке повторения стоит, когда следующее и сколько в нём терминов.

Под ним блок «Стоит перечитать»: термины, последняя проверка которых закончилась ошибкой. Термин уходит из списка после первого верного ответа на повторении. Это не счётчик ошибок за всё время.

Ниже карта терминов: два уровня, внутри пять разделов кодификатора со счётчиком «изучено из». У каждого термина название и пять точек — его шаг. Названия неизученных видны, карточки закрыты. Карточку изученного термина можно открыть в любой момент.

**Сессия.** Тот же каркас, что у визарда домашек. В шапке полоса прогресса и счётчик по терминам этой сессии: «Выучено 2 из 5» в изучении, «Пройдено 7 из 20» в повторении. Номеров вопросов нет — очередь меняется, когда термин возвращается на круг. Выход — стрелка «назад» в шапке сайта, как на других страницах ученика; прогресс сохраняется по ходу сессии. Меню платформы на экранах сессии свёрнуто (на компьютере — в кнопку «Раскрыть меню»).

**Итог.** Сколько верно с первого раза, сколько корма, список терминов с ошибками (они же попадают в «Стоит перечитать»), сколько терминов ждут завтра.

## Игровой отклик

Всё ниже — только показ. На расписание, корм и результат это не влияет; анимации сделаны на GSAP, без него тренажёр работает так же, но неподвижно.

- **Стопка карточек.** Задание лежит карточкой поверх одной-двух следующих. Решённая карточка отбрасывается в сторону (верно — вправо, мимо или «ещё не запомнил» — влево), под ней видна новая.
- **Отклик на действие.** Буква впрыгивает в клетку; верный ответ проходит по клеткам волной. В квизе выбранный вариант перелетает в слот. Полоса прогресса двигается плавно. На телефоне — короткая вибрация на верный ответ.
- **Рыба.** На широком экране маскот ученика всегда стоит справа от карточки: вокруг него кольцо прогресса, под ним счётчик «Выучено» и серия. На телефоне рыбы на экране обычно нет — она выезжает сверху, только когда ей есть что сказать, и уходит со следующим заданием. Прогресс и серия на телефоне — полоской в самом низу, на месте меню платформы (на экранах сессии меню скрыто).
- **Прогресс совпадает с подписью.** «Выучено 1 из 5» — полоса или кольцо заполнены на пятую часть. Промежуточные шаги (карточка, квадратики) прогресс не двигают. Радуется верному ответу, задумывается на ошибке и остаётся задумчивой до следующего задания. Грустной эмоции нет.
- **Рыба говорит.** Результат ответа сообщает она, а не плашка в карточке. На телефоне рыба появляется сверху только на время реплики. Фразы лежат в `config/terms.php` (`phrases`): на каждую ситуацию несколько вариантов, одна и та же не звучит дважды подряд. Тон — дружелюбный, молодёжный, на «ты»; правила:
  - рыба напарник, а не учитель: не объясняет очевидное и не оценивает ученика;
  - на ошибку отвечает фактом — что это за понятие и чей признак выбран, а не утешением;
  - о действиях ученика не говорит в прошедшем времени, чтобы не угадывать пол;
  - между признаками квиза, на карточке знакомства и на подсказке молчит.
- **Пояснения после ошибки.** Рыба утверждает только то, что прямо записано в базе:
  - *введено название другого понятия из базы* — говорит, как оно связано с нужным: «понятие шире», «частный случай», «оба — виды понятия „…“», «их часто путают». Связь берётся из `parent` и `confusable_with`;
  - *в квизе выбран чужой признак* — называет понятие, чей он, и ту же связь, если она есть;
  - *к паре есть заметка преподавателя* — звучит она, вместо шаблона про связь;
  - *в названии две-три неверные буквы* (не больше четверти длины) — «почти», без повтора названия: оно уже стоит в клетках.
- **Ответ в клетках.** Верно — зелёная волна и галочка. Неверно — буквы ученика по одной переворачиваются в правильные, клетки с промахом на секунду жёлтые.
- **Без лишних нажатий.** После верного ответа кнопки «Далее» нет: через секунду-две карточка уходит сама. После неверного экран ждёт «Далее», и рыба с репликой остаётся на месте.
- **Серия.** Счётчик верных ответов подряд внутри сессии. Ошибка его обнуляет. Корма не даёт, между сессиями не переносится.
- **Награда.** На итоге заработанная пицца летит к рыбе, и та ест. За 3 корма — конфетти.

**Дашборд.** Компактная карточка «N терминов ждут повторения» с кнопкой.

## Админка

Страница «Термины», четыре вкладки.

**Импорт.** Заливка JSON. Сначала предпросмотр: что добавится, изменится, исчезнет; применяется после подтверждения.

- Термины сопоставляются по `slug`, признаки по `id`. Прогресс учеников не трогается.
- Термин, исчезнувший из файла, скрывается, а не удаляется.
- `id` признаков нельзя перенумеровывать после запуска: на них ссылаются репорты.
- Файл не принимается, если нарушена целостность: дубли `id`, группа из одного признака, несуществующий `parent`.

**Фото.** Раздел «Термины» в админке (`/admin/terms/photos`) или команда `php artisan terms:photos <папка>` — для первой заливки целой папки. В админке выбранные файлы уходят на сервер по одному, так что пачка в 190 фото не упирается в лимиты PHP на размер запроса. При загрузке создаётся размытая копия для квадратиков (мягкое пятно, сюжет не угадывается), оба файла хранятся под случайными именами. Пакетная загрузка. Файл сопоставляется с термином по имени из поля `image`. После загрузки — отчёт: что сопоставлено, какие файлы лишние, у каких терминов фото нет. Термин без фото работает, место под картинку занимает заглушка.

**Репорты.** Список по признакам со счётчиком.

**Доступ.** Привязка к курсам и выдача отдельным ученикам.

Блок тренажёра в отчёте по ученику (`/admin/users/{id}`): изучено, просрочено, самые слабые термины.

## Не входит в первую версию

- репорты в телеграм;
- новые уровни рыбы;
- напоминания о повторении;
- серии дней подряд — убраны намеренно, чтобы не наказывать отстающих.
