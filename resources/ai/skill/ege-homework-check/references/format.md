# Форматы файлов

## Выгрузка из кабинета (вход)

```json
{
  "format": "poltavskiy-homework-check/v1",
  "export_id": "exp-20261014-1530-ab12",
  "created_at": "2026-10-14T15:30:00+03:00",
  "note": "Проверь этот файл скиллом ege-homework-check и верни файл результата.",
  "sources": {
    "src1": "Текст-источник к заданиям 17–20 (один на несколько заданий)…"
  },
  "items": [
    {
      "id": "s250-t16",
      "submission_id": 250,
      "task_id": 16,
      "subject": "Обществознание",
      "rules": "obshchestvoznanie",
      "number": "18",
      "max_score": 2,
      "task_text": "Формулировка задания…",
      "source_id": "src1",
      "criteria": "Критерии оценивания номера от школы…",
      "school_recommendations": "Рекомендации по проверке…",
      "exemplar_answer": "Образцовый ответ / пояснение…",
      "hint": "Подсказка, которую видел ученик…",
      "student_answer": "Ответ ученика…"
    }
  ]
}
```

| Поле | Что это |
| --- | --- |
| `id` | Ключ задания в работе: `s<submission_id>-t<task_id>`. Возвращается в результате без изменений. |
| `subject` | Предмет (название категории в кабинете), может быть `null`. |
| `rules` | Имя файла правил предмета в `references/` без `.md`, или `null`, если отдельных правил нет. |
| `number` | Номер задания в ЕГЭ, может быть `null`. |
| `max_score` | Максимальный балл за задание в этой домашке. Итоговый балл — целое число от 0 до него. |
| `source_id` | Ключ в `sources` с текстом-источником, или `null`. |
| `criteria`, `school_recommendations`, `exemplar_answer`, `hint` | Могут быть `null`. |

## Результат (выход)

Один объект на каждое задание выгрузки. Поля — те же, что описаны в `base.md` в разделе «Что ты возвращаешь», плюс `id` (и для удобства `submission_id`, `task_id`).

Строка `results.jsonl`:

```json
{"id": "s250-t16", "submission_id": 250, "task_id": 16, "elements": [{"element": "Три признака налога", "student_wrote": "обязательность, безвозмездность, законность", "counted": false, "reason": "«законность» повторяет условие задания — неверная позиция"}, {"element": "Объяснение связи функции государства с ростом", "student_wrote": "государство обеспечивает потребности…", "counted": true, "reason": "функция взята из текста, связь раскрыта"}], "extra_elements_with_errors": [], "criteria_scores": [{"criterion": "Задание 18", "score": 1, "max_score": 2}], "score": 1, "rationale": "Правильно приведён только один элемент ответа (2-й). В первом элементе признак «законность» повторяет условие задания.", "comment": "Объяснение связи получилось хорошо: ты взял функцию из текста и показал, как она влияет на рост. А вот в признаках налога «законность» не засчитывается — она уже есть в самом задании. Вместо неё можно было назвать, например, денежную форму налога.", "needs_human_review": false, "review_reason": ""}
```

Итоговый файл собирает `scripts/finalize_result.py`:

```json
{
  "format": "poltavskiy-homework-check-result/v1",
  "export_id": "exp-20261014-1530-ab12",
  "results": [ { "id": "s250-t16", "…": "…" } ]
}
```
