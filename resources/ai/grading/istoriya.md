# Правила проверки: история (ЕГЭ 2027)

Источники: методические материалы ФИПИ для предметных комиссий по проверке заданий с развёрнутым ответом ЕГЭ 2026 по истории и проект демоверсии ЕГЭ 2027 по истории. В 2027 году часть 2 — это задания 13–22: добавлено новое задание 15, бывшие задания 15–21 сдвинулись на единицу, задания 20 и 22 изменились. Если критерии школы для конкретного номера расходятся с этими правилами, действуют критерии школы.

## Как определить тип задания

Номер в запросе мог быть проставлен ещё по нумерации 2026 года. Поэтому тип задания определяй прежде всего по формулировке, а номер используй как подсказку:

## Общие правила для заданий 13–22

- Орфографические и пунктуационные ошибки не снижают балл.
- «Каждый элемент может быть засчитан только при условии отсутствия неверных позиций в этом элементе наряду с верной»: если ученик в одном элементе перечисляет несколько вариантов («1917, 1918, 1919 гг.»; «Гангутское, Гренгамское сражение»), а верен только один, элемент не засчитывается. Если все перечисленные варианты верны (например, два командующих, оба участвовали в битве), элемент засчитывается.
- Точность формулировок: «революция» вместо «революция 1905–1907 гг.» / «Первая российская революция» — не засчитывается. Требуемая степень детализации видна из задания и критериев.
- Неточность — незначительное искажение, не меняющее смысла. Например, неверные инициалы при верной фамилии допустимы, если в истории нет другого крупного деятеля с этой фамилией («Н.А. Косыгин» — неточность), но «Ф.А. Милютин» не засчитывается: непонятно, о каком из братьев Милютиных речь. Существенная ошибка делает позицию неверной; специально снижать балл за неточности не нужно — их учёт прописан только в задании 21.
- Если ученик перепутал порядок элементов, но смысл очевиден («Ватутин, „Уран“» при вопросе сначала об операции, потом о командующем), засчитывай. Если же надо было назвать двух деятелей на разных должностях и они переставлены без пояснений («Жуков, Сталин» вместо «Сталин, Жуков»), — не засчитывай: нельзя понять, знает ли ученик, кто какую должность занимал.
- Картинки к заданиям 16 и 17 в проверку не передаются. Сверяйся с образцовым ответом и критериями; обоснование в 16 оценивай по тому, насколько оно однозначно ведёт к ответу и согласуется с образцом. Если без изображения нельзя понять, верно ли обоснование, включай `needs_human_review`.

## Задание 13 — атрибуция источника

Три элемента (например: год, глава правительства, лидер партии). Каждый — без неверных позиций в элементе.

Шкала: три элемента — 2; любые два — 1; один или ответ неправильный — 0.

## Задание 14 — поиск информации в источнике

Три вопроса по тексту. Ответ — цитата или сжатый пересказ близко к тексту. Формулировка ученика должна по смыслу соответствовать вопросу: искажение смысла при пересказе делает ответ неверным (например, «почтение царь выказывает ко всем» вместо «ко всем старшим по службе лицам» — не засчитывается).

Не засчитывается переписанный целиком объёмный отрывок, в котором наряду с верным ответом есть информация, не имеющая прямого или косвенного отношения к вопросу: это попытка «поймать» ответ, не найдя его. Если же весь переписанный фрагмент относится к ответу — засчитывается.

Шкала: три вопроса — 2; два — 1; один или ответ неправильный — 0.

## Задание 15 (новое в 2027) — связь со всеобщей историей

По сюжету отрывка нужно назвать связанные с ним события, личности, войны всеобщей истории (пример из демоверсии: Суворов перешёл Альпы → назовите военачальника Древнего мира, войско которого тоже преодолело Альпы, — Ганнибал; назовите войну — Вторая Пуническая война / Пуническая война / война Рима с Карфагеном). Ответы короткие, проверка — сверка с верным ответом в критериях / образце с учётом допустимых вариантов названия.

- Элемент 1 засчитывается только без неверных позиций наряду с верной.
- Если элемент 2 указан правильно, но ученик добавил для конкретизации ошибочные сведения сверх требования задания (например, неверную точную дату войны), эти сведения не учитываются — элемент засчитывается.

Шкала: оба элемента — 2; любой один — 1; ответ неправильный — 0.

## Задание 16 — вывод по изображению с обоснованием

Элемент 1 — вывод (событие, личность, руководитель и т. п.), элемент 2 — обоснование.

- Если элемент 1 неверен или не указан, за задание 0 баллов, независимо от обоснования.
- Элемент 1 засчитывается только без неверных позиций наряду с верной.
- Обоснование не обязано совпадать с образцом, но должно однозначно указывать именно на этот ответ. «Медаль посвящена Гангутскому сражению, потому что на ней Пётр I» — не обоснование: при Петре I было много сражений.
- Обоснование с фактической ошибкой, искажающей смысл (неверно названы воюющие стороны), не принимается; с неточностью, не искажающей смысла, — принимается.

Шкала: вывод и обоснование — 2; только вывод — 1; вывод неверен / не указан — 0.

## Задание 17 — памятник культуры по изображениям

Элемент 1 — цифра выбранного памятника, элемент 2 — сведения о нём (скульптор, монарх, место, стиль — что требует задание).

- Если цифра неверна или не указана, за задание 0 баллов, второй элемент не оценивается.
- Каждый элемент — без неверных позиций («Екатерина II, Павел I» — не засчитывается). Равнозначные формулировки допустимы («Екатерина Великая»).

Шкала: цифра и второй элемент — 2; только цифра — 1; цифра неверна — 0.

## Задание 18 — Великая Отечественная война, два источника

Три элемента: (1) атрибуция обоих отрывков (битва, операция), (2) уточняющий элемент, связанный с первым (например, командующий фронтом в этой битве), (3) информация из одного отрывка в явном виде.

- Элементы 1 и 2 — без неверных позиций. Несколько позиций, все верные (два командующих, оба участвовали), — засчитывается; если среди них есть неверная — нет.
- Элемент 3 — цитата или сжатый пересказ; переписанный объёмный отрывок с посторонней информацией не засчитывается (как в 14). Элемент 3 должен быть полным: если в тексте названы два обстоятельства («туман и снегопад»), а вопрос во множественном числе, одно («снегопад») не засчитывается.
- Порядок элементов — см. общие правила.

Шкала: три элемента — 3; два — 2; один — 1; рассуждения общего характера, ответ неправильный — 0.

## Задание 19 — причины и последствия

Три пункта а), б), в), для каждого задано направление (политическая причина, последствие для образования и т. п.). Каждый пункт — без неверных позиций. Могут быть указаны причины и последствия, отличные от образца. В качестве причин принимаются и предпосылки, и повод.

Главный вопрос: действительно ли указанная причина породила указанное последствие, и соответствует ли она направлению из задания. Не засчитываются:

- обобщённые оценочные суждения вместо конкретного факта («Польша подверглась политическому давлению», «изменилась система управления» — без указания, в чём именно);
- отдалённая и несущественная связь, если она не раскрыта в ответе (восстание 1830–1831 гг. → независимая Польша 1918 г.);
- «последствие», которое на самом деле часть самого события (правительство, созданное в ходе восстания);
- фактические ошибки («падение активности сейма» вместо его упразднения).

Шкала: три элемента — 3; два — 2; один — 1; рассуждения общего характера, ответ неправильный — 0.

## Задание 20 (изменено в 2027) — применение понятия

Нужно вспомнить смысл понятия и ответить на вопросы, применяя его к историческому контексту (пример из демоверсии: «полюдье» — как полюдье связано с восстанием древлян? — Игорь в ходе полюдья решил повторно собрать дань, чем спровоцировал восстание; чем Ольга заменила полюдье? — сбором дани через погосты (места сбора) и уроки (фиксированный размер)).

- Отдельно давать определение понятия не требуется; оценивается, верно ли ученик ответил на каждый вопрос и видно ли из ответа понимание понятия.
- Каждый элемент — без неверных позиций. Ответ «вокруг» вопроса, общие слова о понятии без ответа на вопрос — не засчитываются.
- Ответ на второй вопрос должен быть полным по существу: если в образце два компонента, проверь, не потерян ли смысл (например, «Ольга установила погосты» без указания, что это места сбора дани, — оцени, понятен ли смысл; если сомневаешься — `needs_human_review`).

Шкала: ответы на два вопроса — 2; на один — 1; рассуждения общего характера, ответ неправильный — 0.

Примечание: если задание сформулировано по-старому (2026) — «раскройте смысл понятия, приведите один исторический факт, конкретизирующий понятие применительно к истории России»: определение должно содержать родовую принадлежность и видовые отличия, однозначно указывающие на понятие (не подходящие одновременно к мозаике, иконе и т. п.), без ошибочных элементов; факт — исторически верный, конкретный, не повторяющий использованное в определении; 2 — определение и факт, 1 — только одно из двух, 0 — ни того, ни другого.

## Задание 21 — сравнение

Тезис (обобщённое оценочное суждение о сходстве или различии по признаку(-ам)) и два обоснования.

Тезис:

- должен содержать информацию именно о том, что требуется (о различиях в положении дворянства, а не в политике по отношению к нему);
- не засчитывается тезис «объекты были разными / сходными» и рассуждения общего характера вместо сравнения;
- не засчитывается тезис, где объекты «сравнены» по разным критериям (служилое сословие ↔ получило привилегии);
- может содержать несколько критериев сравнения;
- если тезисов несколько, оценивается только первый и его обоснования.

Обоснования:

- для различия — каждое обоснование содержит два исторических факта, по одному для каждого объекта; для сходства — один или несколько фактов (факт может относиться к обоим объектам);
- отсутствие явления у одного объекта при наличии у другого — тоже факт;
- совокупность событий («было одержано несколько побед», «получили множество привилегий») фактом не считается;
- обоснование должно по смыслу обосновывать именно этот тезис; спорное (можно доказать и обратное) не принимается; обоснование, повторяющее тезис, не принимается; несопоставимые факты (служба ↔ телесные наказания) не принимаются;
- если ученик разбил одно обоснование на два «половинчатых» по одной линии сравнения, объедини их в одно; если же из них непонятно, что именно сравнивается, — не засчитывай;
- только здесь учитывается неточность: частично неверный факт, исключение неверной части которого делает обоснование правильным (неверный год). Если ошибка в основном факте (его нужно заменить, а не убрать), обоснование неверно.

Шкала:

- 3 — верный тезис и два корректных обоснования;
- 2 — верный тезис и одно корректное обоснование; ИЛИ верный тезис и два обоснования, в которых есть неточность(-и);
- 1 — верный тезис и одно обоснование с неточностью; ИЛИ тезис неверен / не сформулирован, но есть хотя бы одно корректное суждение с фактами, позволяющими сравнить объекты; ИЛИ тезис верен, есть такое суждение, но ни одно суждение не обосновывает тезис;
- 0 — иные ситуации; тезис без обоснований — тоже 0.

## Задание 22 (изменено в 2027) — аргументы, история России

Два аргумента в подтверждение заданной точки зрения, только по истории России. При изложении обязательно используются исторические факты.

- Аргумент — это не просто факт, а объяснение связи фактов с точкой зрения: почему они её подтверждают (например, для «реформы 1540–1560-х гг. были реакцией на события»: боярское правление после смерти Елены Глинской сопровождалось борьбой знатных родов, расхищением казны и неправым судом → для примирения и опоры на разные слои Иван IV в 1549 г. созвал Земский собор).
- Аргумент с фактической ошибкой не принимается.
- Второй аргумент не должен опираться на факты, уже использованные в первом; если опирается — он не принимается.
- Если аргументов три и более, оцениваются только первые два.
- Аргумент должен подтверждать именно заданную точку зрения, а не близкую по теме.

Шкала: два аргумента — 2; один — 1; аргументы не сформулированы, рассуждения общего характера, ответ неправильный — 0.

Примечание: если задание сформулировано по-старому (2026) — один аргумент для России и один для зарубежной страны, максимум 3: оба аргумента — 3; только один (для России или для другой страны) — 2; аргументов нет, но приведено не менее двух фактов, которые очевидно можно использовать для аргументации, — 1; иначе 0. Если аргументов для одной страны несколько, оценивается только первый.
